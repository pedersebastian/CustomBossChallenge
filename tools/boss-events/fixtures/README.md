# Samples for the tests of the boss events tools

For the backfill's tests:

- `bloonswiki-sample.txt`: three events (Vortex10, Bloonarius33, Dreadbloon32New) from Blooncyclopedia's
  [2022](https://www.bloonswiki.com/Event_history:Boss_Bloon_Event/2022) and
  [2025](https://www.bloonswiki.com/Event_history:Boss_Bloon_Event/2025) event history pages, under
  [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Only the event templates are kept.
- `jxu-Dreadbloon32New-*.json`: the API's metadata for Dreadbloon32New, from
  [jxu/btd6-events](https://github.com/jxu/btd6-events/tree/bf88fabd02e01343e96812a6e7285fb3abca7ffb/bosses/Dreadbloon32New_mi9oruss/metadata).
- `dcm-*.json`: Ninja Kiwi's challenge models for Vortex10 and Bloonarius33, from
  [jxu/btd6-events](https://github.com/jxu/btd6-events/tree/bf88fabd02e01343e96812a6e7285fb3abca7ffb/BossDataDecrypted).

The rules themselves are Ninja Kiwi's.

For the archiver's tests:

- `api-bosses.json`: Ninja Kiwi's `https://data.ninjakiwi.com/btd6/bosses` on 12 Nov 2026, cut down to three
  events: Dreadbloon39, Vortex48 (both new then) and Lych62 (already archived).
- `api-Vortex48-*.json`: the API's `.../bosses/Vortex48_mw4au3ui/metadata/standard` and `/elite`, the same day.
